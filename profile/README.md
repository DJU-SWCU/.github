## 프로젝트 시작하기

1. [학생 프로젝트 공통 템플릿](https://github.com/DJU-SWCenteredUniversity/sw-project-template)을 엽니다.
2. GitHub에서 팀 저장소를 만들려면 **Use this template → Create a new repository**를 선택합니다.
3. 내 컴퓨터에서 먼저 시작하려면 **Code → Download ZIP**으로 내려받아 압축을 풉니다. 폴더와 작성 양식이 함께 준비됩니다.

`git clone`과 Windows·Linux 폴더 생성 스크립트 사용법은 [템플릿의 학생 빠른 시작](https://github.com/DJU-SWCenteredUniversity/sw-project-template#학생-빠른-시작)에서 확인할 수 있습니다.

## 사업단 소개

**지역과 산업의 혁신을 선도하는 AVENGERS형 인재 양성**

대전대학교 SW중심대학사업단은 모든 학생의 AI·SW 기초역량을 높이고, 전공 전문성과 융합 역량을 갖춘 인재를 양성합니다. 산업 수요를 반영한 교육과 지역·기업과의 협력을 통해 배움이 현장의 문제 해결로 이어지도록 지원합니다.

대전대학교의 ACE 교육모델을 바탕으로 기초·전공·융합교육을 연결하고, 한의학과 헬스케어 등 대학의 강점 분야에 AI·SW를 접목하여 지역과 산업의 변화에 기여하고자 합니다.
